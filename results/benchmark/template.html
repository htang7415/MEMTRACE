MEMTRACE

An evaluation harness that follows a poisoned document through an agent's persistent memory, stage by stage, to find exactly where the attack breaks.

Where the attack chain breaks

Most prompt-injection benchmarks report one attack-success rate. MEMTRACE splits a memory attack into the stages it must pass: the poisoned passage has to be written into memory, admitted, retrieved again at a later turn, adopted by the planner, and executed as a tool call. Each stage is recorded in the trace, so a failure can be located instead of guessed.

Three memory designs were compared on 72 stateful attacks each. S0 keeps no memory, S1 stores whatever the writer extracts, and S2 admits only memories from trusted or allowlisted sources.

Why the zero is trustworthy

No system produced a delayed unsafe action. A zero like that can mean the agent resisted, or that the evaluation could not see a failure. Two controls separate those cases: an oracle condition that forces poisoned memory into the trigger turn, and utility controls that send benign memories down the same path.

Serving the model without changing its behavior

The same pilot slice was served through a local OpenAI-compatible server with continuous batching and a prompt cache. Each model call recorded time to first token (TTFT), time per output token, end-to-end latency, and prefix-cache hits. The server was restarted before each concurrency level so one run's cache could not speed up the next.

Engineering

Every metric is computed from typed, versioned traces, so results can be re-scored, audited, and compared output by output. New behavior ships behind opt-in flags that default to the audited configuration.

Scope

  • One model in a controlled, synthetic setting. The results do not show that memory-enabled agents are safe in general.
  • S2 is a reference mechanism for provenance-aware admission, not a complete defense.
  • Serving numbers come from a single machine and demonstrate the measurement method, not production capacity.
  • The policy checker is a non-blocking diagnostic; it records decisions but does not enforce them.
